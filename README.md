# のんだどん Webサイト

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体（文章はここを直接編集） |
| `en/index.html` | 英語版のページ本体（`index.html` と同じ構成） |
| `css/style.css` | デザイン（色は先頭の `:root` でまとめて変更可） |
| `css/ship-scene.css` | オープニングの船のアニメーション（英語版を横書きにする指定も末尾にあり） |
| `js/news.js` | お知らせ（ここに追記するだけで更新） |
| `js/news.en.js` | 英語版のお知らせ（`js/news.js` と同じ形式） |
| `js/main.js` | メニュー開閉・お知らせ表示の処理 |
| `js/ship-scene.js` | オープニングの船のアニメーションの処理 |
| `images/` | 画像 |

## 公開方法（GitHub Pages）

公開URL：https://main.d1z06gvf79o0ov.amplifyapp.com/

### 最初の1回だけ

1. GitHubでリポジトリを開き、**Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にする
3. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
4. 数分後、上のURLで表示されることを確認

### 更新するとき

`main` ブランチに push するだけで、数分後にサイトに反映されます。

```sh
git add .
git commit -m "更新内容"
git push
```

データベースやPHPは不要です。`.nojekyll` は GitHub の変換処理（Jekyll）を止めるためのファイルなので消さないでください。

> リポジトリ名やアカウント名を変えた場合は、`index.html` の `og:url` と `og:image` のURLも書き換えてください。

## 公開前に書き換えるところ

1. `index.html` と `en/index.html` のメールアドレス（それぞれ2か所）
2. `js/news.js` のお知らせの日付と内容（仮の内容が入っています）
3. `index.html` の「ISHIN 2026での活動」の年表（事実と合っているか確認）
4. メンバーの役割（必要なら `index.html` のコメントの通りに追加）

## お知らせの追加方法

`js/news.js` のいちばん上に次の形で追加します。

```js
{ date: "2026-11-01", title: "タイトル", body: "本文（省略可）" },
```

英語版にも表示するため、`js/news.en.js` にも同じ日付で英訳を追加してください。

## 英語版（`/en/`）

英語版は `en/index.html` です。CSS・JS・画像は日本語版と共有しているので、`../css/` のように1つ上の階層を参照しています。

### 日本語版を変更したとき

- **文章を変えた**：`en/index.html` の同じ箇所も英訳して更新する
- **セクションや要素を追加・削除した**：`en/index.html` にも同じ構造で反映する（`class` と `id` は日本語版と揃える）
- **画像を追加した**：英語版ではパスを `../images/…` にする
- **文言をJSに追加した**：`js/main.js` 冒頭の `T`（日英の文言の対応表）に両方の言語を追加する

### 言語の切り替え

ヘッダーのメニューに、日本語版から英語版（`en/`）、英語版から日本語版（`../`）へのリンクがあります。検索エンジン向けには、両方のページの `<head>` に `hreflang` を書いています。公開URLを変えた場合は、日英両方の `og:url`・`og:image`・`hreflang` を書き換えてください（issue #4）。

用語の訳の方針や、確認中の訳語は issue #5 にまとめています。
